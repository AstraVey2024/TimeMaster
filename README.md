# TimeMaster / 序程项目工作台

包含两个功能页面的浏览器本地 Web 程序：

- **项目排期**：x-spreadsheet 在线表格，领域横向活动模板，day/week/Month 周期，复杂依赖与共用节点，停工顺延、主导依赖标红、合并单元格识别、原样 Excel 导出。
- **时间轴编辑**：OSA Timeline，里程碑与时间段、领域分组、拖动、原位编辑、悬浮标签、50 层撤销、TAG 版本记录、本地文件、图片/报表导出。

排期页的“转换到时间轴”会先重新计算日期，再按领域生成分组。`$` 共用关键节点去重后在分组外显示，日期待定的项目列入提示。现有时间轴会保留“排期转换前备份”。

## 开发与验证

需要 Node.js 22+ 和 Python 3。

```sh
npm install
npm test
npm run dev
```

浏览器访问 http://127.0.0.1:5173 。前端无需构建，直接托管 `dist/` 即可。不要通过 `file://` 打开 ES modules。

浏览器资源已随源码保存在 `dist/vendor/`，无需 CDN；依赖安装用于回归测试及维护第三方资源。

## 文件结构

- `dist/index.html`：项目排期入口。
- `dist/sheet-app.mjs`、`sheet-model.mjs`：表格编辑、数据解析与回写。
- `dist/engine.mjs`：依赖排序、日期与停工日计算。
- `dist/merged-cells.mjs`、`xlsx-export.mjs`：合并单元格、Excel 往返。
- `dist/plan-to-timeline.mjs`：排期到时间轴转换。
- `dist/timeline/`：时间轴完整源代码，保留仓库已有悬浮标签定位和原位编辑改进。
- `dist/vendor/`：x-spreadsheet 1.1.9、ExcelJS 4.4.0 浏览器包及各自 MIT 许可证。
- `tests/`：排期转换与原时间轴回归测试。
- `AGENTS.md`：开发约定。

## 计算及编辑约定

Month 按活动开始日所在的实际日历月份计算，月末截断；day/week 以自然日为基础，遇到配置的停工日期暂停计工。周末是否停工可单独设置。

同一行合并的周期/依赖/人力读取左上角内容，活动标题合并后视为一个活动。跨字段合并或一个合并日期格对应不同完成日会明确报错。节点 ID 默认隐藏，导出后仍隐藏。

导出 Excel 保留当前布局、字体、颜色、合并关系与日期结果；重新计算需在网页中执行。导出的日期不是 Excel 排期公式。

## 数据与迁移

localStorage 保存浏览器草稿，IndexedDB 保存历史快照。源码不包含浏览器实时项目、附件或站点绑定。新增排期模板使用通用模拟数据；已有 `project/` 文件沿用仓库原有内容，本次不修改。

切换域名后存储独立，请从旧网址导出 JSON 后在新环境导入。项目排期与时间轴各自保存；转换为一次性快照，后续编辑不会自动双向同步。

## 验证范围

运行 `npm test` 覆盖原时间轴功能及新增的领域分组、共用节点去重、待定日期、合并周期、合并标题、合并日期冲突、Excel 往返等逻辑。DOM harness 不等于真实浏览器验收；站点版此前已验证双页切换及转换流程，GitHub 合并版本另保留了原仓库改进。
